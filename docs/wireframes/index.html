Karbon POS · Wireframes (Fase 1)

Wireframes de baja fidelidad para validar flujo y jerarquía antes de las fases de UI. Paleta blanco / negro / gris con verde #22C55E como acento; cada estado de mesa tiene color propio y siempre va acompañado de texto. Se adaptan a modo claro/oscuro según el sistema.

6 · Cocina (KDS)
